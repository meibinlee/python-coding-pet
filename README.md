# 코딩 펫 키우기

중학교 정보 수업 복습을 위한 정적 React + Vite 앱입니다. 6개 영역의 30개 템플릿에서 값을 무작위 생성하며, JavaScript 순수 함수로 정답을 계산합니다. 예시 코드를 실행하지 않습니다.

오늘까지의 구현·검증·배포 상태와 남은 작업은 [개발 진행 기록](PROGRESS.md)에 정리했습니다.

## 실행

Node.js 22 최신 LTS 또는 24 권장.

```sh
npm ci
npm run dev
npm run test
npm run build
npm run preview
```

처음에는 치이카와·하치와레·우사기 중 친구 하나를 고르고 펫 이름(기본 코코)을 정합니다. 먹이·청소·놀기를 누르면 문제를 풀 수 있습니다. 정답은 해당 상태 +15(최대 100), XP +10이며, 오답은 XP −5(최저 0)이며 상태 수치는 그대로입니다. 같은 문제의 추가 클릭에는 차감·보상을 중복 적용하지 않습니다. 다음 문제에서만 새 문제를 생성합니다. 한국 시간 기준 하루 10문제까지 제출하며 정답·오답 모두 1문제를 사용합니다. 답하기 전에 닫으면 횟수를 쓰지 않습니다. 한국 시간 자정에 횟수가 새로 시작합니다. 아기는 50XP·실제 48시간·돌본 날짜 2일, 성체는 150XP·아기 진입 후 실제 96시간·아기 단계 돌본 날짜 4일을 모두 채우면 성장합니다. 오답으로 XP가 줄어도 이미 도달한 단계는 유지하며 새로고침해도 보존합니다. 상태 감소 타이머는 생략했으며 방치로 죽거나 초기화되지 않습니다.

## 오늘의 돌봄

- 메인 화면에 오늘 제출한 문제와 남은 문제 수를 표시합니다.
- 문제를 모두 사용한 뒤에도 **기본 돌봄**과 펫 **쓰다듬기**가 가능합니다.
- 기본 돌봄은 한국 날짜 기준 하루 한 번입니다. 문제 횟수·XP·세 상태 수치는 바뀌지 않지만, 성장에 필요한 돌본 날짜를 하루 기록합니다. 정답 돌봄도 같은 날짜 기록에 포함되며 하루에 여러 번 돌봐도 1일입니다. 오답·접속·쓰다듬기는 날짜를 추가하지 않습니다.
- 체크리스트에는 정답으로 수행한 먹이·청소·놀이와 기본 돌봄을 표시합니다. 모두 완료해야 하는 의무는 없습니다.
- 펫을 클릭하거나 Tab으로 선택한 뒤 Enter/Space를 누르면 짧은 하트와 말풍선을 보여 줍니다. 게임 기록은 바뀌지 않습니다.
- 탭 복귀와 한국 자정에 오늘의 날짜를 재검사하며, 답안은 **제출 시점의 날짜**에 계산합니다.

`NEXT_DEVELOPMENT_PLAN.md` 승인본 중 일일 문제·기본 돌봄·쓰다듬기·체크리스트를 구현했습니다. **시간·돌봄 날짜·XP를 함께 확인하는 성장도 구현했습니다.** 다음 성장까지 남은 시간, XP, 돌본 날짜를 표시합니다. 오래 쉬어도 한 번에 두 단계 성장하지 않으며 아기 진입 시점부터 96시간을 새로 셉니다. 질병·간호·회복도 구현했습니다. 배부르면 10분 낮잠도 구현했습니다. 배설물·청소 연출도 구현했습니다. 휴가 모드도 구현했습니다. 성장 앨범과 사용자 제공 이미지 기반의 세 친구 선택도 구현했습니다.

## 건강과 간호

- 알은 아프지 않습니다. 아기·성체는 마지막 유효한 돌봄 이후 **실제 24시간을 초과**하면 아픕니다. 오프라인 시간도 포함합니다.
- 정답 돌봄·기본 돌봄·간호가 관리 시각을 갱신합니다. 접속·오답·쓰다듬기는 갱신하지 않습니다.
- 아프면 기본 돌봄 버튼이 **간호하기**로 바뀝니다. 기본 돌봄과 간호는 하루 횟수를 공유합니다. 오늘 기본 돌봄을 쓴 뒤 새로 아프게 되었다면 회복을 시작할 첫 간호 1회는 추가로 가능합니다.
- 회복에는 **첫 간호 후 실제 24시간**과 **첫 간호와 다른 한국 날짜의 추가 간호**가 모두 필요합니다. 추가 간호를 먼저 했다면 기록을 보관했다가 24시간이 찼을 때 회복합니다.
- 아파도 문제와 정답 보상·일반 돌봄·쓰다듬기는 가능합니다. 자동 성장은 회복 후 다시 확인합니다. 죽음·초기화·레벨 하락은 없습니다.
- 회복 후 관리 시각을 새로 설정합니다. 기존 기록에 건강 정보가 없다면 업데이트 적용 시점부터 건강 기준을 시작해 즉시 아프지 않게 합니다. XP·단계·성장 시각은 보존합니다.

## 배부르면 낮잠

- 깨어 있을 때 먹이 문제를 맞혀 보상을 받은 뒤 배부름이 100이면 **10분간 낮잠**을 잡니다. 이미 100이어도 새 먹이 정답으로 시작할 수 있습니다.
- 시작·종료 시각을 저장합니다. 새로고침해도 종료 시각은 유지되고, 정확히 10분이 지나면 깨어납니다. 접속만으로 다시 잠들지 않습니다.
- 자는 동안 새 먹이 문제는 쉬고 청소·놀이를 선택합니다. 이미 열린 먹이 문제는 그대로 제출할 수 있으며, 보상을 받아도 수면 종료 시각은 늘어나지 않습니다.
- 기본 돌봄·간호·쓰다듬기도 계속 가능합니다. 질병과 수면 상태를 별도로 표시하며, 낮잠이 성장·질병·회복의 실제 경과시간을 멈추지 않습니다.

## 방 정리와 청소 연출

- 기본 발생 기준은 **먹이 정답 2회**입니다. 상태 감소 타이머를 생략한 앱이므로 청결도가 낮아지기를 기다리지 않고 플레이 중 연출을 볼 수 있습니다.
- 방에 배설물 1개를 표시하며 추가 수치 감소·XP 벌점·사망은 없습니다. 계속 먹여도 표시가 무한히 쌓이지 않습니다.
- **청소 문제 정답**으로 표시를 제거하고 먹이 누적을 0으로 되돌립니다. 청소 오답·놀이·기본 돌봄·간호·접속만으로는 없어지지 않습니다.
- 청소 정답 후 펫에게 돌아오면 짧은 반짝임과 완료 문구를 보여 줍니다. reduced-motion에서는 움직임 없이 표시합니다.
- 먹이 누적과 방 상태는 새로고침 후에도 유지합니다. 기존 펫 기록에는 누적 0부터 추가하며, 성장·건강·수면·XP는 보존합니다.

## 휴가 모드

- 메인 화면에서 **휴가 시작하기 / 휴가 마치기**로 전환합니다. 상태는 새로고침·재방문 후에도 유지됩니다.
- 휴가 중에는 질병 판정, 성장 경과시간, 진행 중인 회복 시간이 함께 멈춥니다. 시작 전에 이미 아팠다면 아픈 상태는 유지하며, 휴가만으로 회복되지 않습니다.
- 휴가를 마치면 **남아 있던 시간부터** 이어갑니다. 원래 성장·간호 시각과 돌본 날짜를 보존하고, 시계별 휴가 누적 시간을 따로 차감합니다.
- 휴가 중에는 문제 제출·기본 돌봄·간호를 잠시 쉽니다. XP·상태 보상·돌본 날짜·문제 사용량은 추가되지 않으며, 오답 차감도 없습니다. 쓰다듬기는 가능합니다.
- 일일 문제 수는 실제 한국 날짜를 따릅니다. 지나간 날짜의 미사용 문제를 이월하지 않으며, 휴가를 같은 날 시작·종료해도 이미 사용한 횟수는 유지됩니다.
- 10분 낮잠은 휴가 중에도 원래 시각에 끝납니다. 낮잠과 장기 휴가는 별개입니다.
- 여러 탭에서 같은 시작·종료 요청이 겹쳐도 한 번만 처리합니다. 기존 저장 기록에는 휴가 꺼짐과 누적 정지 시간 0부터 추가합니다.

## 친구 선택과 성장 앨범

- 처음 시작할 때 **치이카와·하치와레·우사기** 중 한 친구를 선택합니다. 세 친구는 같은 문제·보상·성장 규칙을 사용합니다.
- 선택은 현재 펫에 저장됩니다. 새로고침해도 유지되며, 시작한 뒤에는 현재 친구를 바꾸지 않습니다. 처음부터 다시 시작할 때에는 확인창을 거쳐 새 친구를 고를 수 있습니다.
- 기존 기록에 친구 선택이 없다면 기록을 초기화하지 않고 한 번 선택합니다. XP·단계·돌봄·건강·휴가·수면 기록은 그대로 유지됩니다.
- 사용자가 제공한 PNG 35장을 `public/pets/characters/`에 웹 경로용 이름으로 복사했습니다. 첨부 원본은 수정하지 않았습니다.
- 성장 단계와 청소·놀이·기쁨·배고픔·수면 상태에 따라 이미지를 선택합니다. 해당 이미지가 없으면 같은 캐릭터·단계의 기본 이미지에 기존 상태 표시를 함께 사용합니다. 우사기 성체와 모든 아기의 수면 이미지는 기본 모습으로 대체합니다.
- **성장 앨범**에 처음 만난 시각과 실제 아기·성체 진입 시각, 선택한 친구와 단계별 모습을 저장합니다. 시각은 한국 시간으로 표시하며 같은 단계는 중복 기록하지 않습니다.
- 업데이트 전 성장 시각을 알 수 없는 기존 기록은 현재 단계를 `이전부터 함께한 모습`으로 표시합니다. 과거 성장 시각이나 존재하지 않는 기록을 만들지 않습니다.

## 파일 구성

- `src/data/characters.js`: 세 친구와 상태별 이미지 경로, 빠진 상태의 기본 이미지 선택.
- `src/game/album.js`: 성장 기록 중복 방지·이전 및 기존 펫의 첫 친구 선택.
- `src/data/questionTemplates.js`: 정확히 30개 생성 템플릿. W04는 반복 횟수를 질문합니다.
- `src/game/questions.js`: 문자열 비교(의미 있는 공백 보존), Fisher–Yates 셔플, 최근 5개 중복 재생성(최대 10회), 동일 템플릿 3연속 방지.
- `src/game/rules.js`, `storage.js`: 보상 잠금, 시간·날짜·XP 성장, 방 정리 규칙 및 저장 이전·검증.
- `src/game/vacation.js`: 휴가 상태, 정지된 시각, 해제 시 시계별 휴가 누적 처리.
- `src/game/sleep.js`: 낮잠 시작·만료, 새 먹이 문제 제한 및 수면 기록 검증.
- `src/game/health.js`: 질병 발생, 첫 간호·추가 간호·회복 시간 및 버튼 사용 가능 여부.
- `src/game/time.js`, `daily.js`: 한국 날짜, 일일 제출·기본 돌봄, 탭 간 저장 처리.
- `src/components/`: 펫·상태·키보드 포커스를 가두는 네이티브 문제 dialog.
- `tests/`: 템플릿당 100회 생성, 표시된 코드 리터럴에 기반한 독립 정답 계산, 보상 및 저장 테스트.

## 캐릭터 이미지 관리

현재 캐릭터 이미지는 사용자 제공 PNG이며 원본 참조 파일은 `src/ref_img/`에 있습니다. 실제 웹앱은 `public/pets/characters/<친구 ID>/`의 파일을 사용합니다. 이미지 추가·교체 시 `src/data/characters.js`의 경로도 함께 확인하세요. 파일명을 ASCII로 통일해 운영체제의 한글 정규화나 공백 때문에 배포 경로가 달라지지 않도록 했습니다.

기존 자체 제작 `public/pets/egg.svg`, `baby.svg`, `adult.svg`는 알 수 없는 캐릭터 경로의 기본 이미지로 유지합니다.

## GitHub Pages 배포

저장소: https://github.com/meibinlee/python-coding-pet

사용자 승인 후 공개 저장소로 전환하고 GitHub Actions 기반 Pages를 설정했습니다. **배포 워크플로는 수동 실행**만 허용합니다. 별도 `Test and build` 워크플로는 main 푸시와 PR에서 테스트·프로젝트 경로 빌드를 실행하며 배포하지 않습니다.

배포 주소: https://meibinlee.github.io/python-coding-pet/

1. 위 저장소에 최신 코드를 push합니다.
2. Settings → Pages → Build and deployment에서 **GitHub Actions**를 선택합니다.
3. 기본 `base`는 `./`라서 프로젝트 하위 경로의 스크립트·캐릭터 이미지를 상대 경로로 로드합니다. 명시적인 경로를 원하면 Settings → Secrets and variables → Actions → Variables에 `VITE_BASE_PATH`를 `/저장소이름/`으로 설정합니다. 사용자 최상위 `<username>.github.io` 저장소는 `/`입니다.
4. Actions → Deploy to GitHub Pages → Run workflow를 수동 실행합니다. `npm ci`, 테스트, 빌드를 거쳐 `dist`가 배포됩니다.
5. 배포 주소에서 이미지, 새로고침 저장 복원, 모바일 및 키보드 조작을 확인합니다.

로컬에서 프로젝트 경로 빌드 확인:

```sh
VITE_BASE_PATH=/python-coding-pet/ npm run build
npm run preview
# http://127.0.0.1:4173/python-coding-pet/ 접속
```

## 데이터 저장 한계

`coding-pet-save-v1` 키로 현재 브라우저의 localStorage에만 저장합니다. 계정·DB·백엔드·외부 API·분석 스크립트는 없습니다. 펫 이름만 입력하며 실명이나 학번을 요구하지 않습니다. 다른 브라우저나 기기와 동기화되지 않으며 사이트 데이터 삭제나 시크릿 모드 종료로 기록이 사라질 수 있습니다. 저장 실패 시 안내와 함께 메모리에서 게임을 계속합니다. 손상되거나 범위가 잘못된 핵심 기록은 기본값으로 복구합니다. 기존 저장 키를 유지하고 payload를 schemaVersion 2로 이전합니다. v1 기록의 이름·XP·세 상태·기존 단계와 오늘 문제 사용량을 보존하며, 새 시간 기준은 이전 시점부터 시작합니다. 기존 성체는 그대로 성체입니다. 오늘 이미 수행한 돌봄도 반영합니다. 성장 기준 시각을 저장하므로 재방문으로 시간이 다시 시작되지 않습니다. 미래 관리 시각이나 잘못된 일일 기록은 펫을 유지하며 보정하고 안내합니다. 관리 시각은 질병 판정에 사용합니다. 건강 정보가 없는 이전 기록은 첫 업데이트 때 건강 기준 시각만 새로 시작하며, 이미 저장된 성장 시각은 다시 시작하지 않습니다. 초기화는 확인창을 통과해야 합니다.

제출과 기본 돌봄은 최신 저장 상태를 읽은 뒤 처리합니다. Web Locks 지원 브라우저에서는 같은 출처의 여러 탭을 잠금으로 직렬화합니다. 미지원 환경에서는 최신 기록을 다시 읽지만 완전한 동시 제출 방지는 보장하지 않습니다. 저장 실패 후에는 현재 탭의 메모리 기록을 우선해 횟수가 되돌아가지 않게 합니다.

클라이언트 데이터와 기기 시계는 사용자가 변경할 수 있으므로 일일 제한은 교육용 개인 플레이를 위한 장치입니다.
